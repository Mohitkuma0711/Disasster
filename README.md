# Disaster Victim Detection

A full-stack application for disaster victim detection using AI/ML analysis on imagery and sensor data.

## Project Structure

- `/backend` - Python FastAPI backend service
- `/frontend` - React + Vite + Tailwind CSS frontend application

## Setup & Running

### Backend
1. Navigate to `backend/`:
   ```bash
   cd backend
   source venv/bin/activate
   pip install -r requirements.txt
   uvicorn main:app --reload
   ```

### Frontend
1. Navigate to `frontend/`:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
